**Demultiplexer – Verilog & Zybo FPGA**

**Overview**

Implementation of a Digital Demultiplexer using Verilog, followed by simulation and hardware implementation on the Zybo FPGA development board.

**Function**
The demultiplexer routes a single input signal to one of multiple output lines based on the select input.

**Files**
* `DEMULTIPLEXER.v` – Verilog design
* `TB_DEMULTIPLEXER.v` – Testbench
* 'Makefile'
* 'flow.json'
* 'zybo.xdc'
* 'DEMULTIPLEXER.bit'
* `screenshots/` – Simulation and Zybo FPGA implementation results

**Tools & Technologies**
Verilog • Zybo FPGA • Vivado • Digital Logic Design

**Result**
The demultiplexer was verified through simulation and successfully implemented and tested on the Zybo FPGA board.
